# Neon Syndicate — Telegram Mini App кликер

Играбельный прототип Telegram Mini App (без бэкенда), переработанный под модульную архитектуру.

## Что реализовано
### Базовые механики (которые вы просили)
1. Система улучшений.
2. Система скинов.
3. Система рейтинга.
4. Система ежедневных заданий.
5. Система сюжета и сюжетных заданий с артефактами за главу.

### 5 новых механик
1. **Достижения** (кристаллы за milestones).
2. **Активные способности** с откатами.
3. **Динамические события** (временные глобальные модификаторы).
4. **Экспедиции** (таймерные миссии с наградами).
5. **Перерождение (prestige)** с эссенцией.

## Структура проекта
- `src/core` — состояние, экономика, localStorage, Telegram bootstrap.
- `src/systems` — каждая игровая функция в отдельном модуле.
- `src/ui` — рендер core-статистики.
- `src/config` — игровые конфиги.

## Запуск
```bash
python3 -m http.server 8000
```
Открыть `http://localhost:8000`.

> Для запуска как Telegram Mini App привяжите URL к Web App кнопке бота.
