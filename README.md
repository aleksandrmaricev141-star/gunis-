# Империя древних русов (HoI4 1.10)

В кампании 1936 года на месте Албании сразу отображается **Империя древних русов**.

## Что настроено
- Стартовая страна на теге `ALB` переименована в **Империю древних русов**.
- Стартовый правитель: **Олег Перуновичес**.
- Идеология: **Языческий милитаризм** (`pagan_militarism`).
- Партия: **Род Перуна**.
- Выборов нет (`elections_allowed = no`), власть наследственная.
- В 1938 году власть переходит к **Александру Великому Маричеву**.
