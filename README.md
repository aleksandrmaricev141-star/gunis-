# Орловская область — 2D глобальная стратегия (прототип)

Мини-игра под Windows с простым **собственным 2D-движком** (игровой цикл + сцены) и карьерной механикой:

- Старт: **Глава района**.
- Можно взять под контроль до **3 районов**.
- Затем повышение до **Мэра города Орёл**.
- Максимум: **Губернатор Орловской области**.

## Почему так удобно делать

Для быстрого прототипа удобно использовать **Python + Pygame**:
- быстро запускается;
- просто рисовать контурные карты;
- легко собрать `.exe` под Windows через PyInstaller.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python src/main.py
```

## Управление

- `SPACE` — получить 1 очко заслуг.
- `N` — попытка взять новый район.
- `R` — попытка повысить должность.
