# Империя Древних Руссов (HoI4 1.10)

Теперь государство появляется **сразу в 1936 году на месте Албании**.

## Как это сделано
- В `country_tags` тег `ALB` перенаправлен на файл страны «Империя Древних Руссов».
- Локализация `ALB` заменена: на карте вместо «Албания» показывается «Империя Древних Руссов».
- История `ALB` переопределена: стартовый правитель — **Олег Перунович**.
- В 1938 году по событию лидер меняется на **Александр Великий Маричев**.

## Идеология страны
- Установлена уникальная идеологическая ветвь: **Языческий милитаризм** (`pagan_militarism`).
- Партия: **Род Перуна**.
- Выборов нет (`elections_allowed = no`), власть наследуется внутри правящего рода.

## Главное
В новом запуске кампании 1936 вы сразу увидите ваше государство вместо Албании.
