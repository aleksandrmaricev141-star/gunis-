# Neon Syndicate — Telegram Mini App кликер

Играбельный прототип Telegram Mini App с вертикальным форматом 9:16, вкладками-меню и модульной архитектурой.

## Что обновлено
- UI переведён в формат **9:16** (как мобильное мини-приложение).
- Лишние блоки убраны во **вкладки меню**: Ядро / Прогресс / Миссии / Продвинутое / Гильдия.
- Добавлена система **гильдий**:
  - вступление в гильдию,
  - бонусы к клику/пассиву,
  - ежедневные квесты гильдии,
  - рейтинг гильдий.

## Основные механики
1. Улучшения
2. Скины
3. Рейтинг
4. Ежедневные задания
5. Сюжет + артефакты
6. Достижения
7. Способности
8. Динамические события
9. Экспедиции
10. Перерождение
11. Гильдии

## Структура
- `src/core` — state/storage/economy/telegram
- `src/systems` — каждая механика отдельным модулем
- `src/config` — игровые данные
- `src/ui` — рендер базовых статов

## Запуск
```bash
python3 -m http.server 8000
```
Откройте `http://localhost:8000`.
