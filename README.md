# Государство древних руссов (HoI4 1.10)

Мод добавляет альтернативно-историческую страну **«Государство древних руссов»**.

## Что добавлено
- Тег страны: `DVR`.
- Название страны: «Государство древних руссов».
- Стартовая территория: Албания (state `44`, если используется ванильная нумерация).
- Албания перестает существовать: ее территория переходит под контроль `DVR`.
- Столица: Асгард (через столицу в state `44`).
- Стартовый правитель: **Олег Перунович**.
- Смена руководителя в 1938 году: **Александр Великий Маричев**.
