# YouTube Channel Live Counter + Telegram Bot

Теперь проект делает две вещи:
- показывает live-статистику канала в веб-интерфейсе;
- отправляет эту статистику и уведомления в Telegram-бота.

## Что есть

### Web UI
- подписчики в реальном времени (polling);
- просмотры канала в реальном времени;
- общее количество роликов;
- таблица последних роликов (просмотры + комментарии).

### Telegram Bot
- команда `/start` — подключить чат;
- команда `/stats` — полный срез по каналу и роликам;
- команда `/videos` — только ролики;
- авто-уведомления при росте:
  - подписчиков;
  - просмотров канала;
  - просмотров роликов;
  - комментариев на роликах.

> Важно: YouTube API не дает webhook на «кто именно подписался/прокомментировал». Поэтому бот отправляет уведомления по **изменению счетчиков** между циклами опроса.

## Настройка

1. Создайте Telegram-бота через `@BotFather` и получите токен.
2. Получите YouTube API key и включите **YouTube Data API v3**.
3. Скопируйте окружение:

```bash
cp .env.example .env
```

4. Заполните `.env`.

## Запуск веб-части

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## Запуск Telegram-бота

```bash
source .env
node bot.js
```

Потом напишите боту `/start`, чтобы он запомнил ваш `chat_id` и начал отправлять уведомления.
