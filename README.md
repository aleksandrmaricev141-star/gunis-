# Neon Syndicate — Telegram Mini App

Полностью мобильный прототип (9:16) с нижним меню, профилем, гильдиями, уровнями и расширенным прогрессом.

## Новое в этой версии
- Нижнее меню: **Ядро / Профиль / Гильдия / Рейтинг / Магазин**.
- Профиль игрока со сводкой прогресса.
- Мягкий редизайн интерфейса (светлая палитра, мягкие тени, комфортный UI).
- Создание гильдий за кристаллы.
- Реальные рейтинги без ботов (по реальным данным локального состояния).
- Расширенные механики гильдий: уровень, казна, баффы, квесты.
- Уровни персонажа (XP/уровень влияет на доход).
- Сюжетные главы обновлены до **минимум 10 заданий на главу**.
- Подготовлен блок покупки кристаллов за реальные деньги (UI-заглушка, без подключения платежей).
- Добавлена админ-панель (локальная, для тестов).

## Запуск
```bash
python3 -m http.server 8000
```
Откройте `http://localhost:8000`.
