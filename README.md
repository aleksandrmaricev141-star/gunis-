# Скифы — MVP прототип браузерной MMORPG

Этот репозиторий содержит **игровой вертикальный срез** по ТЗ проекта «Скифы»:

- фронтенд (HTML/CSS/JS) с мобильным UX;
- backend на PHP (REST API);
- безопасная регистрация/логин (bcrypt + JWT + rate limit);
- серверная модель формул RPG;
- базовая симуляция пошагового боя;
- схема БД SQLite с ключевыми таблицами для масштабирования.

## Быстрый запуск

```bash
php -S 0.0.0.0:8080 -t .
```

Открыть: `http://localhost:8080/public/`

## API

### POST `/backend/register.php`

Поля:
- `name`
- `email`
- `password`
- `password_confirm`
- `faction`
- `class`

### POST `/backend/login.php`

Поля:
- `email`
- `password`

Ответ:
- `token` (JWT)
- `expires_in`

## Что реализовано из ТЗ

- Классы и специализации;
- Основные и вторичные статы;
- Формулы урона/HP/крита/антикрита;
- Тактический пошаговый PvE-симулятор (1v1, серверный расчет);
- Подготовленная схема БД под кланы, аукцион, сезоны, рейды, политику.

## Ограничения MVP

- Email подтверждение и anti-bot помечены как следующий этап;
- JWT хранится в localStorage (для продакшена лучше HttpOnly cookies + refresh-token ротация);
- Симулятор боя демонстрационный, без сетевого PvP matchmaking.
