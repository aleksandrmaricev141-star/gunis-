# Вертикаль: Орловская область — Godot-only

Проект полностью переписан под **Godot 4.x** (GDScript).

## Состав
- `project.godot` — конфиг проекта.
- `scenes/Main.tscn` — основная сцена.
- `scripts/Main.gd` — сборка UI и обработка действий.
- `scripts/core/GameState.gd` — симуляция и формулы.
- `scripts/ui/MapCanvas.gd` — отрисовка карты и выбор районов кликом.
- `data/districts.json` — полный набор: 24 района + 3 города и гео-контур области.

## Реализовано
- Полная административная выборка Орловской области.
- Гео-карта (контур + точки центров районов/городов).
- Режимы карты: `LOY/INF/ECO/RISK/SERV`.
- Месячный тик и расчёт `BUD/POL/CAD/EXP/MED`, а также `CS/SUP/RDI`.
- Команды управления: антикризисная и экономическая.
- Старт с 2020 года, выбор стартового района и отдельное меню запуска.
- Пауза игры (ON/OFF) и расширенная карточка информации по району.
- У каждого района свой цвет на карте.

## Запуск
1. Открыть папку `godot/` в Godot 4.x.
2. Запустить `res://scenes/Main.tscn`.


## Фото-карта
Для адаптации предоставленной фотографии поместите её в `godot/assets/orlov_map_reference.png` — `MapCanvas` подхватит файл автоматически и поверх будут работать hover-подсветка границ и выбор районов.
