# Godot prototype: «Вертикаль: Орловская область»

Это переписанный прототип на **Godot 4 (GDScript)**.

## Что реализовано
- Все 24 района Орловской области + 3 города областного значения (Орёл, Ливны, Мценск).
- «Реальная» гео-основа карты: контур Орловской области и географические координаты центров районов/городов.
- Месячный симуляционный цикл: обновление `INF/ECO/SERV/LOY/RISK`, ресурсов (`BUD/POL/CAD/EXP/MED`), событий и метрик `CS/SUP/RDI`.
- Базовые действия: следующий месяц, +3 месяца, запуск фокуса, развертывание антикризисной/экономической команды, выбор района кликом на карте.

## Запуск
1. Откройте папку `godot/` в Godot 4.x.
2. Запустите сцену `res://scenes/Main.tscn`.

## Примечание
Координаты центров районов заданы по реальной географии (приближённо, для прототипа).
