# Вертикаль: Орловская область — Godot-only

Проект полностью переписан под **Godot 4.x** (GDScript) с интерфейсом в стиле grand strategy (в духе HOI4).

## Состав
- `project.godot` — конфиг проекта (стартовая сцена: меню).
- `scenes/Menu.tscn` + `scripts/Menu.gd` — отдельное главное меню.
- `scenes/Main.tscn` + `scripts/Main.gd` — игровая сцена.
- `scripts/core/GameState.gd` — симуляция и формулы.
- `scripts/ui/MapCanvas.gd` — отрисовка карты и выбор районов кликом.
- `data/districts.json` — полный набор: 24 района + 3 города и гео-контур области.

## Главное меню
- Играть
- Загрузить (stub)
- Настройки (stub)
- Выход

## Реализовано
- Старт кампании в 2020 году.
- Выбор стартового района в отдельном окне перед началом.
- После старта нельзя переключиться и играть за другой район.
- У каждого района свой цвет.
- Пауза по кнопке и по `ESC`.
- Базовые параметры района: население, бюджет, поддержка народа + NPS.
- Вкладки: Политика, Инфраструктура, Экономика, Социальная сфера, Безопасность.
- Банк (займы под процент) и иностранные тендеры на инфраструктуру/коммерческие объекты.
- Карьерная лестница: глава района → глава фаланги → мэр Орла + фаланга → губернатор области.
- NPS автоматически развивается по всем районам (в т.ч. не выбранным игроком).

## Запуск
1. Открыть папку `godot/` в Godot 4.x.
2. Нажать Play (запустится `Menu.tscn`).

## Фото-карта
Для адаптации предоставленной фотографии поместите её в `godot/assets/orlov_map_reference.png` — `MapCanvas` подхватит файл автоматически и поверх будут работать hover-подсветка границ и выбор районов.
